# Add To Cart (`cart-card`)

> A product card that is only a photo until you open it.

- Source page: https://www.pinui.xyz/components/cart-card
- Registry JSON: https://www.pinui.xyz/r/cart-card.json
- Type: `registry:component`
- Dependencies: motion
- Files: CartCard.tsx, cart-card.css
- License: MIT (c) Rachit Thakur / Shadcn Labs — keep the header comment

## Install

```bash
npx shadcn@latest add "https://www.pinui.xyz/r/cart-card.json"
```

## Use

Read the sibling source files before adapting. Keep class prefix and motion values,
swap copy/brand colours for the project's tokens, and add a
`prefers-reduced-motion: reduce` path.
