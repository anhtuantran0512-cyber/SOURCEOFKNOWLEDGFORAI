# Theme Switch (`theme-switch`)

> A theme toggle that rains, drips or sets off fireworks to change the theme.

- Source page: https://www.pinui.xyz/components/theme-switch
- Registry JSON: https://www.pinui.xyz/r/theme-switch.json
- Type: `registry:component`
- Dependencies: none
- Files: ThemeSwitch.tsx, theme-switch-engine.ts, theme-switch.css
- License: MIT (c) Rachit Thakur / Shadcn Labs — keep the header comment

## Install

```bash
npx shadcn@latest add "https://www.pinui.xyz/r/theme-switch.json"
```

## Use

Read the sibling source files before adapting. Keep class prefix and motion values,
swap copy/brand colours for the project's tokens, and add a
`prefers-reduced-motion: reduce` path.
