# Liquid Tabs (`liquid-tabs`)

> A notifications card whose active tab is liquid, flowing from tab to tab.

- Source page: https://www.pinui.xyz/components/liquid-tabs
- Registry JSON: https://www.pinui.xyz/r/liquid-tabs.json
- Type: `registry:component`
- Dependencies: motion
- Files: LiquidTabs.tsx, liquid-tabs.css
- License: MIT (c) Rachit Thakur / Shadcn Labs — keep the header comment

## Install

```bash
npx shadcn@latest add "https://www.pinui.xyz/r/liquid-tabs.json"
```

## Use

Read the sibling source files before adapting. Keep class prefix and motion values,
swap copy/brand colours for the project's tokens, and add a
`prefers-reduced-motion: reduce` path.
