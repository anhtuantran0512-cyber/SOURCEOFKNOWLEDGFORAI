# Swap Card (`swap-card`)

> A token swap card where every number rolls and the button is liquid.

- Source page: https://www.pinui.xyz/components/swap-card
- Registry JSON: https://www.pinui.xyz/r/swap-card.json
- Type: `registry:component`
- Dependencies: motion
- Files: SwapCard.tsx, swap-card.css
- License: MIT (c) Rachit Thakur / Shadcn Labs — keep the header comment

## Install

```bash
npx shadcn@latest add "https://www.pinui.xyz/r/swap-card.json"
```

## Use

Read the sibling source files before adapting. Keep class prefix and motion values,
swap copy/brand colours for the project's tokens, and add a
`prefers-reduced-motion: reduce` path.
