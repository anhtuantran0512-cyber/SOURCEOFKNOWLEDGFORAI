# Search Card (`search-card`)

> A centred search bar that rises and morphs open into a card of recent searches.

- Source page: https://www.pinui.xyz/components/search-card
- Registry JSON: https://www.pinui.xyz/r/search-card.json
- Type: `registry:component`
- Dependencies: motion
- Files: SearchCard.tsx, search-card.css

## Install

```bash
npx shadcn@latest add "https://www.pinui.xyz/r/search-card.json"
```

## Use

Read the sibling source files before adapting. Keep class prefix and motion values,
swap copy/brand colours for the project's tokens, and add a
`prefers-reduced-motion: reduce` path.
