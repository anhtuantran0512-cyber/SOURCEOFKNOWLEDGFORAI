Demo: Tailwind Prev / Next Arrow Carousel with Native Scroll Buttons
Source: https://codefronts.com/snippets/tailwind-css-image-carousel/tailwind-prev-next-arrow-carousel-scroll-button/

Real previous/next buttons that page the gallery one slide at a time, generated by the browser via ::scroll-button() — focusable, auto-disabling at the ends, and needing no JavaScript. Anchor-link arrows sit underneath as the universal fallback.

## CSS
```css
@import "tailwindcss";

@theme {
  --color-tcar17-bg: #eef2fb;
  --color-tcar17-bg: oklch(0.95 0.015 265);
  --color-tcar17-acc: #2563eb;
  --color-tcar17-acc: oklch(0.52 0.2 262);
  --font-tcar17-sans: 'Plus Jakarta Sans', system-ui, sans-serif;
}

.tcar-17 {
  width: 100%;
  min-height: 100svh;
}

.tcar-17 ::selection {
  background: var(--color-tcar17-acc);
  color: #fff;
}

.tcar17-scroller::-webkit-scrollbar {
  display: none;
}
/* CSS Carousel scroll buttons: no utility form, so the whole control lives here. */

.tcar17-scroller::scroll-button(left),
.tcar17-scroller::scroll-button(right) {
  position: absolute;
  top: 50%;
  translate: 0 -50%;
  z-index: 3;
  width: 44px;
  height: 44px;
  border: 0;
  border-radius: 50%;
  cursor: pointer;
  background: #fff;
  color: var(--color-tcar17-acc);
  font-size: 22px;
  font-weight: 700;
  line-height: 1;
  box-shadow: 0 8px 20px -8px oklch(0.35 0.1 265 / 0.6);
  transition: scale .2s, opacity .2s;
}

.tcar17-scroller::scroll-button(left) {
  content: "\2039";
  left: 12px;
}

.tcar17-scroller::scroll-button(right) {
  content: "\203A";
  right: 12px;
}

.tcar17-scroller::scroll-button(left):hover,
.tcar17-scroller::scroll-button(right):hover {
  scale: 1.08;
}

.tcar17-scroller::scroll-button(left):disabled,
.tcar17-scroller::scroll-button(right):disabled {
  opacity: .35;
  cursor: default;
}

.tcar17-scroller::scroll-button(left):focus-visible,
.tcar17-scroller::scroll-button(right):focus-visible {
  outline: 3px solid var(--color-tcar17-acc);
  outline-offset: 2px;
}
/* One rule decides which control set the user sees. */

@supports selector(::scroll-button(right)) {
  .tcar17-fallback {
    display: none;
  }
}

@media (prefers-reduced-motion: reduce) {
  .tcar17-scroller {
    scroll-behavior: auto;
  }

  .tcar17-scroller::scroll-button(left),
    .tcar17-scroller::scroll-button(right) {
    transition: none;
  }
}
```
