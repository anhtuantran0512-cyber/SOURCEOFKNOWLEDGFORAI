A documentation sidebar with a search field, four independently collapsible sections and an active page marker. Each section animates to its true height with the grid-rows-[0fr] → grid-rows-[1fr] technique — no max-height guess — and every section header is reachable by Tab with a visible focus ring. Zero JavaScript.
