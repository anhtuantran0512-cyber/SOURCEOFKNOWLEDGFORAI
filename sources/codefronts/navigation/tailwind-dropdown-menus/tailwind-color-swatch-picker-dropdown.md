An 18-swatch palette in a dropdown, each swatch scaling up on hover with a pure-CSS tooltip. Two things are worth the port: the swatch colours are inline custom properties (eighteen one-off hex values are not a design scale), and the tooltip is after:content-[attr(data-name)] — an attr() read, in a utility.
